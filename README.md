# MOTIONSALT Upscaler

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/motionssalt/upscale/blob/main/MOTIONSALT_Upscaler.ipynb)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Anime upscale & color-correction, running on a free Colab GPU.

## Use it

1. Open the notebook in Colab (badge above).
2. `Runtime` → `Change runtime type` → `GPU`.
3. Run the four cells top-to-bottom:
   - **Connect** — one-click setup.
   - **Pick your file** — choose a video from your computer.
   - **Enhance** — pick a model and quality, click **Enhance**.
   - **Download** — direct download button, plus a ~1-hour shareable link.
